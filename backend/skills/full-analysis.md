# Полный анализ — аналитический пайплайн (MD-скилл) [Exa Edition]

## Что это

Полный продуктовый анализ по методологии нашей методологии: сегментация, скоринг, unit economics, RAT, executive summary.

Выполняется самим Claude через инструменты — без Node.js, без JSON-парсинга.

**Поиск:** все данные через Exa (нейросемантический поиск — свежее и точнее обычного WebSearch).

**Время:** ~15-20 минут.

---

## Алгоритм

### Шаг 1 — Читай контекст проекта

Выполни `Read projects/[name]/onboarding.md`.

Извлеки и запомни:
- **Описание продукта** — что делает, для кого
- **География** — рынок
- **Стадия** — idea / validation / mvp / growth / scale
- **Цена** — текущая или гипотеза
- **Платящих клиентов** — число
- **Гипотезы сегментов** — от основателя (если есть)
- **Big Job** — главная работа которую решает продукт

Скажи пользователю: *"▶ Фаза 1: Исследую рынок через Exa — пару минут."*

### Шаг 2 — Исследование рынка (Exa)

**ВАЖНО: Exa ищет семантически** — формулируй запросы как описание идеальной страницы, не как ключевые слова. Запрос "blog post comparing competitors in [category] 2026" лучше чем "[продукт] конкуренты".

Выполни 4 поиска через `mcp__exa__web_search_exa`. После каждого — сразу записывай находки.

**Запросы (адаптируй под продукт):**
1. `comparison of [product category] competitors pricing and positioning [geography] 2026` — кто есть на рынке, цены
2. `[product category] market size and growth trends [geography] 2025 2026` — размер рынка
3. `why [target segment] struggles with [problem] and does not use existing solutions [geography]` — non-consumption, барьеры
4. `honest reviews and complaints about [competitor] what users dislike 2025 2026` — незакрытые Jobs у конкурентов

Для конкурентов — дополнительно запусти `mcp__exa__company_research_exa` по каждому найденному конкуренту (до 3 штук). Это даёт глубже: funding, размер, позиционирование.

**Что записывать:**
- Список реальных конкурентов (название, URL, цена, позиционирование, главный незакрытый Job)
- TAM bottom-up: `(аудитория в регионе) × (% с проблемой) × (% готовых платить) × (цена)`
- Ключевые тренды 2025-2026
- **Non-consumption**: кто вообще ничего не делает с проблемой и почему (это часто крупнейший сегмент)

Если свежих данных нет — явно укажи это.

После поиска скажи: *"▶ Фаза 2: Строю сегменты."*

### Шаг 3 — нашей методологии-сегментация

**Шаг 3.1 — Глубокое Jobs Discovery**

Определи три уровня Jobs:
- **Functional Job** — что человек буквально хочет сделать ("создать ролик")
- **Emotional Job** — что хочет чувствовать ("уверенность что справлюсь сам")
- **Social Job** — как хочет выглядеть в глазах других ("эксперт, который идёт в ногу со временем")

> В СНГ Social Jobs часто важнее Functional. Не игнорируй их.

Определи **Struggling Moments** — не абстрактные Jobs, а конкретные ситуации:
- "Пятница вечер, клиент ждёт контент, а у меня нет навыка / инструмента / времени..."
- "Увидел что знакомый уже зарабатывает на этом, а я всё ещё нет..."

Сформулируй:
- **Primary Job:** "Когда [struggling moment], ищу способ [прогресс], чтобы [functional + emotional outcome]"
- **Big Jobs (1-3):** крупные жизненные цели за которыми стоит Primary Job
- **Core Jobs (3-5):** конкретные задачи за которые платят

**Шаг 3.2 — Построй 7-9 сегментов + Non-consumption**

Каждый сегмент = [Кто] + [Struggling Moment] + [Core Job].

**ОБЯЗАТЕЛЬНО добавь сегмент "Non-consumers"** — люди у которых есть проблема, но они не используют ни одно решение. Опиши барьер: цена? Сложность? Не знают что решение существует?

Для каждого сегмента:
- **Название** (формат: "Кто в момент когда...")
- **Struggling Moment** — конкретная ситуация-триггер
- **Core Job** + **Emotional Job** + **Social Job**
- **Switch Story** — что происходит в жизни человека за 3 месяца до покупки продукта подобного нашему? Какой момент был последней каплей?
- **Кто они** — роль, контекст, текущее решение
- **TAM (bottom-up)** — `N × % с проблемой × % платят × цена`, с логикой
- **SAM / SOM**
- **Почему привлекателен** — острота, WTP, конкуренция

**Покажи сегменты пользователю.** Отбери топ-5 для глубокого анализа (включая Non-consumers если выглядят сильно).

### Шаг 5 — Скоринг сегментов

Скажи: *"▶ Фаза 4: Синтез и скоринг."*

**Сначала применяй Gate — если LTV/CAC < 1, сегмент автоматически C, дальше не считай.**

LTV считать правильно:
```
LTV = (AMPPU × GrossMargin%) / MonthlyChurnRate
```
где MonthlyChurnRate = 1 / срок жизни клиента в месяцах (если нет данных — используй benchmark по категории).

**Для сегментов прошедших Gate**, рассчитай балл:

```
Total = JobFit×0.40 + MarketSize×0.25 + Economics×0.25 + Moat×0.10
```

**Оси (0-100):**
- **JobFit** — насколько точно продукт попадает в Struggling Moment + закрывает Emotional/Social Job (не только Functional)
- **MarketSize** — SAM в абсолютных числах (только bottom-up оценки)
- **Economics** — LTV/CAC ratio (healthy >3 = 90+, moderate 1-3 = 50-70, unhealthy <1 = 0/Gate)
- **Moat** — уникальность позиции: есть ли что-то что нельзя скопировать за 3 месяца?

**Конкуренцию НЕ включать отдельной осью** — она уже учтена в Moat и Economics (высокая конкуренция = высокий CAC).

**Категории:**
- **A (70+)** — прошёл Gate + высокий балл, идти сейчас
- **B (50-69)** — прошёл Gate, второй эшелон
- **C (<50 или не прошёл Gate)** — отложить

**Unit economics для топ-3:**
- AMPPU, GrossMargin%, CAC, LTV, LTV/CAC, Payback Period (CAC/AMPPU мес), MonthlyChurn%
- Статус: healthy (LTV/CAC>3, Payback<6мес), moderate (1-3, <12мес), unhealthy (<1)

### Шаг 6 — RAT-анализ

Для A и B сегментов — 3-5 рискованных допущений. Обязательно включи:

**Non-consumption test** (если есть Non-consumer сегмент): "Мы предполагаем что барьер — [X]. Но на самом деле люди могут не осознавать проблему вообще."

**Формат каждого риска:**
- **Допущение** — что именно предполагаем как истину
- **Вероятность провала** (1-5)
- **Импакт** (1-5)
- **Score** = P × I
- **Эксперимент на 30 дней** — конкретный, с метрикой успеха

Покажи топ-5 по Score.

### Шаг 7 — Executive Summary

**Вердикт с условием** (не просто GO/NO-GO):
- **GO** — `A-сегмент [название], LTV/CAC > 3, идти немедленно`
- **GO conditional** — `GO на [сегмент] если [конкретное условие] подтверждено к [дата]`
- **PIVOT** — `текущий оффер слабее чем [конкретный Job] для [конкретный сегмент]`
- **NO-GO** — ни один сегмент не прошёл Gate

**Рекомендуемое позиционирование:**
`Для [кто в момент когда] — [продукт] — единственный способ [прогресс] без [главный страх/барьер]`

**Asymmetric Opportunity:**
Где при минимальных инвестициях максимальный upside? (Non-consumer сегмент, незакрытый Social Job, канал без конкурентов)

**Competitor Response:**
Что сделают топ-2 конкурента если мы войдём в приоритетный сегмент? Есть ли у нас 6 месяцев до ответного удара?

**Следующие 3 шага** (формат RACI-lite):
```
1. [Действие] → KPI: [метрика] → Дедлайн: [дата] → Бюджет: [ресурс]
```

**90-дневный план:**
- Месяц 1 → задача + KPI + кто делает
- Месяц 2 → задача + KPI
- Месяц 3 → задача + KPI + target MRR

## Правила

- **Только свежие данные** — "2026" к каждому Exa-запросу
- **Запросы как описание страницы** — не ключевые слова, а "blog post about X" / "comparison of Y tools 2026"
- **company_research_exa для конкурентов** — глубже чем просто веб-поиск
- **Struggling Moments вместо абстрактных Jobs** — конкретная ситуация, не желание
- **Social/Emotional Jobs обязательно** — в СНГ часто важнее Functional
- **Non-consumption сегмент всегда** — люди которые ничего не делают
- **Gate перед скорингом** — LTV/CAC < 1 = автоматически C, без исключений
- **LTV = (AMPPU × Margin%) / Churn%** — не упрощать
- **TAM только bottom-up** — не % от категории
- **Субагенты параллельно** — не последовательно
- **Вердикт с условием** — не просто GO, а GO если X
- **Сохранять result.md** до показа в чате
